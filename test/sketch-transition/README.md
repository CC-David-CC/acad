# Data-only sketch transition prototype

`web/app/sketcher/headless/sketchTransition.ts` exports two synchronous functions intended for a disposable Worker; neither publishes to a live editor. `replaySketchTransition({revision,sketchJSON,externalParameters})` validates/solves a captured complete native sketch, requires existing `sameRestoredSketch` strict identity/geometry/intent equality and checks saved admission hints against recomputed solver evidence. `addLengthRelationTransition({revision,sketchJSON,externalParameters,intent:{ids:[id,id],factor,offset}})` first validates the source, uses the same `prepareLengthRelation` helper as the editor in a real `HeadlessSketchWorkspace`, verifies only the requested relation was added while prior identities/intent/metadata remain, and independently solves/checks the resulting native state. The history equality helper has a narrow legacy missing-hint allowance, but the current underlying solver refuses missing admission intent before equality; this core does not claim to replay such legacy input. An explicit saved hint does not authorize different classification. No DOM, Canvas, fake window, GUI or ToolManager participates.

Success is `{revision,ok:true,serializedSketch,evidence}` plus `{relation:{objects,status}}` for LengthRelation. Failure is `{revision,ok:false,error:{code,message}}`; the caller's source string cannot be modified. Exact request fields, revision length ≤256, source and result ≤1 MiB UTF-8 and code units, finite nonnegative factor and finite offset are required; solve's existing schema, fixed boundary, generator, residual and domain checks apply. Worker errors/termination are not solver verdicts. A production caller must correlate revision with separately retained source, editor epoch, lifetime, geometry, storage and account state before publication; cancellation, deadlines, guarded atomic hydration, rollback, rendering, actual history and agent/UI transport are not implemented here. Typed source evaluation is not added; unsupported named consumers remain refused by existing validation.

Actual separate Chromium contexts ran the test-only disposable Worker under strict `script-src 'self' 'wasm-unsafe-eval'; worker-src 'self'` CSP; no unsafe-eval or blob Worker. `browser.test.cjs` covers 32 valid locks, successful LengthRelation and its exact serialized record, missing IDs, conflicting locks, changed replay geometry, changed saved admission, invalid external parameter, extra key and >1 MiB UTF-8; source unchanged. `scale.test.cjs` used 32,128,512 independent locks, with 512 replay in 940 ms in the recorded single run. `scale-length.test.cjs` used the same 512-lock fixture and returned a valid candidate in 2313 ms. `scale-hint.test.cjs` changed one accepted saved hint to redundant; the Worker did not finish within the test's 10 s deadline and was terminated, with no published result. ## Shape and input policy follow-up

The follow-up replaces the broad data mask with explicit solver-owned numeric paths by shape. All other shape data is compared exactly; changes to unknown fields or unsupported shapes explicitly refuse. For B-splines only control-point x/y coordinates are presently movable; degree, knots, weights, modes, point IDs, fit points and derived/base-point data remain exact until further qualification. Rigid-group transform may move while membership and local point definitions remain exact. A real Worker length relation moved a dependent circle radius 10→11.4285714286 with both constraints satisfied. Separate synthetic field-policy tests establish that arbitrary authored knot, weight, ID, mode and local rigid-data changes refuse; they are not claims of an observed Worker mutation. External parameters must be a plain own-data finite numeric record; exotic Map/Date/typed arrays and accessors refuse, and rejected requests retain their bounded own-data revision without invoking a getter.
