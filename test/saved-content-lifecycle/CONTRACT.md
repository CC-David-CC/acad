# Saved-content lifecycle: frozen acceptance contract (SOURCE ONLY)

Root executes one complete grouped workflow after source review and a fresh
coherent Core+Host build/stage/pin composition. No tests/build were run while
preparing this packet. Original failures and artifacts are immutable.

The bounded public model is sixteen genuinely authored independent100x50mm
rectangles, followed by one original width edit, Undo/Redo, Save and fresh
Open. Dirty must be false after known saved baseline, true after edit, false
after Undo to exactly saved content (counters unchanged), true after Redo,
and false after the second Save and fresh Open. Cancelled New/Open and close
must preserve source/path/token; explicitly discarding New must create a new
empty document, and reopening the own saved document must restore it.
A refused stale revision must preserve source and dirty state.

A separate genuine10x20x30mm OCCT box receives one public material assignment
named `Boundary-🌐-material`. A valid numeric expression source contains only
`pad = `, spaces and `1`. Whitespace length is calculated once from an actual
first saved JSON file so the astral high surrogate lies at the final16384-code
unit fragment boundary. Material rebind uses the real propose/confirm commands.
The second JSON must contain that exact uncorrupted string, with the pair
crossing the intended UTF16 boundary. No adjustment/retry after a failed run.
Save/reopen both JSON and native CAD through actual Files; independent reader
checks JSON and native archive structure, source, units, assignments and hashes.

All mutation uses registered commands and real themed dialogs. No private
setters/authoring, seeded geometry, fake replies, patched validators, file-delay
injection, filesystem races/faults or foreign accounts. Read-only context,
source, guard, Worker and resource observations are permitted and recorded.
No native JSON/snapshot method is invoked by this driver. Public commands
currently refuse authoring while Files operations own their lease. Earlier
save/newer-edit during that lease, malicious validity callback changes, cleanup
failure and physically forced crashes are SOURCE REVIEW obligations here,
not invented runtime passes. Unknown writes/mutations retain owning contexts.

At least one observed codec Worker must belong to the actual owned context;
all observed codec targets must retire at normal clean close/context retirement.
The live synchronous close guard may only say clean when its manager reports
exact equal; unknown observed cache must mean dirty. The run does not force an
unknown state by mutating internals. It records whether unknown was actually
observed. Dirty close shows the themed confirmation and cancel preserves the
window; clean close after a public exact inspect must remove it without prompt.

Resource measurements are passive. Collect owned frame Long Tasks and main
JS heap plus owned codec Worker heap at natural lifecycle checkpoints. For
this finite representative model require every reported scalar to be finite,
main+owned-codec sampled used heap <=1GiB, and observed main Long Tasks <=1000ms.
A missing observation/API is INCOMPLETE, not zero. This is a coarse acceptance
floor for the stated model, not a128MiB capacity/peak RSS/WASM-memory guarantee.
Accepted-source readbacks/harness captures occur outside measured intervals.

Whole PASS requires all phases, exact current fetch pins and distinct clean
Core/Host/acceptance Git source custody, real submitted/acknowledged browser
writes and whole-file server settlement, and no pending/unknown ownership.
Only then may the separate frozen reader run once and independently verify
saved bytes, source and all original files before/after. No rerun can overwrite
FIRST evidence. This finite result does not itself qualify all CAD1 resources.

The one Unicode padding derivation subtracts the actual initially saved JSON
expression encoding length; it never assumes an empty default expression.
The stale Save refusal is settled only after exact original accepted source
and actual own saved-file version/status remain unchanged. Public normalized
commit flags alone are insufficient refusal evidence.

Source review closure: every fresh Open now records its actual command index,
selected saved artifact SHA and complete detached authored source. Runner and
independent reader compare all histories, original sketches, expression source,
counters, presentation, materials and drawing definitions against the actual
saved file. Ephemeral journal/material-revision tokens are not authored data.
The same Unicode box is saved natively using actual File > Save As to My files
and the themed filename dialog. Its observed browser path/version publication
is the local acknowledgement, then actual browser/server settlement and native
archive readback bind it. The native file must match the JSON authored document
and survive a fresh Open. This is not inferred from the rectangle .cad cases.
Pending mutation clears only on its own acknowledged result or explicit fully
proved refusal; successful read-only inspection cannot clear unknown custody.

R7 repair acceptance: after Undo and before dirty inspection, retain complete
original saved and current authored captures. Their values must match the
independent native archive exactly; record whether actual history insertion
order changed. Dirty must still be false. No coordinate tolerance or document
field omission is added. Record key order is incidental; array order and all
actual authored names/values/field presence remain exact comparison inputs.
