# Experimental selected sketch regions

This branch introduces explicit regions only for non-touching circles and axis-aligned rectangles in planar sketches. A region records its authored outer boundary and all immediate child boundaries, together with the owning face ID. It must resolve against the current sketch; changed/ambiguous descriptors fail rather than selecting a replacement. Region selection and separate/union body policy are persisted as EXTRUDE parameters. Union is limited to connected selected regions. The previous implicit even/odd extrusion is not this feature.

Build the embedded runtime with `CODI_EMBED_NUMERIC=1 CODI_EMBED_MANIFOLD=1 npm run build` and compile `test/webos/webpack.config.cjs` with those same flags. Serve `dist` on loopback under CSP without `unsafe-eval`, run a disposable Chromium with a loopback CDP endpoint, then run the two `*regions-browser.test.cjs` / `region-picking-browser.test.cjs` scripts with puppeteer-core available via NODE_PATH. The first tests four selected ring cases and three nested-island selections with actual OCC and save/reopen, plus disjoint separate bodies, the second exercises actual checkbox and canvas clicks. `region-interactive-edit-browser.test.cjs` adds a circle with actual Chromium mouse events in the reopened sketch and rejects the stale selection. `region-stale-browser.test.cjs` changes a serialized sketch fixture and verifies the old selected region fails resolution and disconnected union is refused without changing existing shells. `region-face-ownership-browser.test.cjs` verifies an actual region cannot be used with a different actual face. `node --test test/learning/{profile-plan,authored-regions}.test.mjs` tests classifier and descriptor invariants.

This is an experimental intermediate checkpoint, not general arrangement or release qualification. In particular cross-frame lifecycle ownership, and edit-driven downstream regeneration still require dedicated end-to-end tests. Native Mesh and intersecting/unknown curve arrangements are not qualified here.

The runtime has separately named OCC EXTRUDE and Native Mesh Box/Boolean operations; it does not have a general engine selector or Native Mesh sketch extrusion. `native-region-refusal-browser.test.cjs` exercises a selected annulus on an actual native box face, requires a visible unsupported message, and checks the native mesh and history are unchanged. Before the guard, the identical request silently produced an OCC shell; the guard therefore refuses the operation instead of implying conversion. It does not prove Native Mesh region support.

`cut-default-browser.test.cjs` exercises the ordinary OCC Cut wizard without supplying a simplify setting and checks the persisted true default plus a through-hole center ray. Before the preset fix it failed with `boolean.simplify: required`. The ray is a bounded opening check, not a complete solid/manifold proof.
