Actual built CAD/Worker API review, not a rendered GUI or signed My files test. CAD source `532352ac24f382df130c216818cba53124c8d974`; fixture `/tmp/codi-rectangle-ui/dist` was built before that commit and embeds its parent revision, so this is tied to observed artifact hashes rather than a clean revision-tagged build. Reproduction uses an isolated host fixture serving this dist, `JSKETCHER_TEST_URL=http://127.0.0.1:19795/node_modules/jsketcher-build/`, `CODI_TEST_CDP=http://127.0.0.1:19374/`, `PUPPETEER_CORE_PATH=/tmp/codi-notebook-provider-quiesce/node_modules/puppeteer-core`, and `/tmp/codi-files-move-node/bin/node test/webos/rectangle-boundary-review.test.cjs`. The test itself does not validate artifact hashes; independently pin fixture bytes before running.

After first accepting a 100×50 mm rectangle, 0.001×0.001 mm at (+1e8,+1e8), (+99999999,+99999999), and (−1e8,−1e8) was refused before commit, preserving previous history and sketch records. A 1×1 mm rectangle at (+1e8,−1e8) was also refused. At (+1e6,−1e6), 0.001×0.001 mm was accepted; all four serialized segment lengths met an absolute 1e-8 mm tolerance, and prior history/sketch records were unchanged. Tests allow refusal for numerical/domain limitations and check preservation; they do not imply all advertised origin/dimension combinations can be built.

The returned refusal for every tested failure was generic `Rectangle request could not be prepared.` Source shows far endpoints beyond 1e8 violate domain and 0.001 at ±1e8 can violate the representation-precision check. `solveWorker.ts` converts all rectangle-draft errors to a generic INVALID response, so callers cannot distinguish a precision/domain limit from other preparation failures. This is a diagnosis/usability gap; this test does not claim a geometric corruption. For each rejected case internal feature IDs may be consumed; authored history and geometry are the asserted boundary.

During actual models-stream notification of a second rectangle, aborting its signal and separately invalidating the synchronous host callback each produced `AbortError` with `committed=true`; both accepted sketches remained. Resetting the document in that notification produced `AbortError` with `committed=true`, suppressed stale later model notifications, and cleared the document as requested; the saved prior envelope reopened with identical history/sketch records. This does not prove atomicity across browser crash, native kernel hangs, or remote persistence.

## Typed diagnostic follow-up

The follow-up splits only known rectangle input errors into `RECTANGLE_DOMAIN` (including far-corner coordinate overflow) and `RECTANGLE_PRECISION`; the CAD API carries those codes and fixed messages to callers. Unexpected draft exceptions still return `INVALID` with the generic message, without forwarding stack traces. Existing domain and numerical tolerances are unchanged. A private full app build used `CODI_EMBED_NUMERIC=1` and an independent dependency copy; its revision marker predates this uncommitted source, so the exact tested output is identified by asset hashes: `index.bundle.js` `14ab9f107940f0439363d517f5c1279033f1bbb1da4149869a5056ed088574ae`, `sketcher.bundle.js` `85a038b2ef773e79617cda56cf3087ab1c3bddc8960c2c052e4cbbd890347a99`, `sketch-solver.aa0157bf66dfa1bfb6dd.js` `552766a0931c21409d26a3edc771262f924fc611d4c8d9376ef26c72ed3c35a0`. The boundary test verifies these explicit hashes via `CODI_CAD_INDEX_SHA`, `CODI_CAD_SKETCH_SHA`, `CODI_CAD_WORKER_PATH` and `CODI_CAD_WORKER_SHA`. It passed against the actual built core and Worker: the in-range near ±1e8 cases report `RECTANGLE_PRECISION`, far-corner overflow reports `RECTANGLE_DOMAIN`, accepted geometry and all state/cancellation assertions remain as above. The real worker/client suite additionally checked both stable messages, malformed inputs, generic fallback for an unsupported unit and worker cancellation; it did not inject an unexpected internal fault. `npm run check-code` passed. A first private app build without `CODI_EMBED_NUMERIC=1` was stopped after CSP refused runtime string evaluation; it was rebuilt with the proper setting. The desktop test helper was copied solely to satisfy fixture construction and was not loaded by these tests. No signed storage or real UI confirmation is claimed.
