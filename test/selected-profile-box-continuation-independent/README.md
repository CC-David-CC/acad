## Read-only source conclusions

`solidOperandRuntime.mjs` selects one exact registered native build from current
output metrics, checking JS/WASM hashes, mountEngine and representation. Box
continuation scans **all current generic outputs**, including native-empty
metadata results. It uses the declared default only when this inventory is
empty. An output with another engine, a mixed registered build, an unavailable
revision or inconsistent binding refuses. It does not convert existing shapes
or re-evaluate them with a fallback build. Build identity here is the registered
native JS/WASM pair and mount/representation; app/bootstrap assets are pinned
separately by this runtime receipt.

`workerSolidCommands.ts` uses that result for the new box's authored revision,
exposes readonly `boxEngineBindings`, and returns engineRevision in the receipt.
A Boolean continues its selected operands' common build. The actual coordinator
first checks current owned registry instances and immutable metric/runtime
binding; the pure selector is not itself a geometry/authentication validator.
