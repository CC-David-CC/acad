# Experimental controlled-mesh3MF Worker adapter, version1

Frozen before implementation against Core9ba304395. Ownership is NEW web/app/cad/export/{controlledMesh3mfProtocol.mjs,controlledMesh3mf.mjs,controlledMesh3mf.worker.mjs,controlledMesh3mfClient.mjs} and this test directory only. No change to core3mf.mjs, project manager, Craft, catalog, defaults, global build or public routes. Materials are authored labels, not physical/safety certificates.

Request exact fields: {version:1,unit:'millimeter',revision,materials,appearances,parts,artifacts}. revision is the captured64lowerhex geometry/material assignment revision. materials[{id,name}], appearances[{id,name,color}], parts[{id,name,regions:[{id,bodyId,featureId,engine:'occ',engineRevision,materialId,appearanceId}]}]. Each artifact is the existing source-bound private-ledger return {op:'solid.manufacturing.mesh.read',contractVersion:1,unit:'millimeter',body:{bodyId,featureId},engine:'occ',engineRevision,metadata,buffer}. Source bindings match region references exactly; duplicate/extra/missing artifacts and duplicate body membership refuse. Metadata/array/strings are bounded own-data records, dense arrays, unique IDs, no getters/coercion. Native handle/name/projection/coordinates are never input metadata. No extra placement: controlled mesh coordinates are already model-space; future placement needs its own explicitly verified contract.

The request classifies already-authorized read artifacts; arbitrary JSON is NOT a native/source/currentness proof. Eventual orchestration must obtain each artifact through readCandidateWorkerManufacturingMesh with permanent discard-only candidate authority and recheck source/history/material revisions around replay/read/encode. This adapter does not grant that authority or verify document membership by itself. revision is an opaque binding captured by that orchestration, not a hash recomputed from arbitrary mesh bytes on Main.

Small capture only on Main: metadata at most64KiB, at most32parts/32totalregions/128material-appearance pairs; bounded material/appearance tables128each. Each standalone intrinsic ArrayBuffer is unique, attached, nonshared, correct declared byteLength, with aggregate input at most8MiB. No vertex traversal/conversion/hash/XML/ZIP there. Transfer every buffer exactly once into a dedicated one-job Worker. Worker repeats exact admission and controlled binary validation, converts Float64/U32 into serializer arrays, validates mesh, emits XML and ZIP via unchanged writeCore3mf. Aggregate150000vertices/250000triangles (per-mesh qualified limits150000/100000) and input8MiB refuse RESOURCE_LIMIT before conversion. Existing serializer XML48MiB bound remains; returned ZIP at most64MiB. These caps belong to encoder/mesh work, not the account's128MiB file limit, and are not peak RSS bounds.

Each part produces an explicit build item. Its sole admitted region is a mesh resource and retained part/region/material/appearance identities are carried in the bounded result mapping; resource ordinals remain file-local. Multiple regions in ONE part are represented in metadata but refuse UNQUALIFIED_REGION_INTERFACE until a real native pair/interface plus compatible tessellation proof is designed/qualified. No AABB/common-volume inference, no independent packing, union/priority or region merging. Unknown material/appearance assignments refuse UNKNOWN_MATERIAL_ASSIGNMENT; never default. Same material/appearance pair shares one basematerials resource entry; different pair remains distinct. Separate parts remain separate build items even when located together; this adapter does not certify their pairwise nonoverlap/arrangement.

Existing serializer validation remains in force: manifold edge/link incidence and conservative shell nesting. Some genuine curved-cavity configurations remain UNSUPPORTED_MESH_DOMAIN. Do not bypass shell validation, infer material-side from one native-solid count, or treat one indexed mesh as cross-region no-overlap proof. Mesh triangle self-intersection/universal geometric validity is not newly certified here; Native source proof and qualified controlled tessellation remain independent prerequisites.

Client input buffers stay attached for refusal before dispatch. After successful transfer, they are consumed even if encode/cancel/deadline later fails. Every error is annotated inputsConsumed (true after transfer; false before; unknown only on ambiguous failed posting), fileCommitted:false. No file operation occurs. Each job has one exact reply bound to the captured small envelope/revision; malformed/wrong/duplicate/out-of-order replies retire the encoder. Client validates result standalone buffer/metadata/identity without byte traversal. Signal cancellation reads intrinsic AbortSignal.aborted and registers/removes with intrinsic EventTarget methods, including preaborted/shadowed fields. One deadline, one Worker; terminate on success/failure/cancel and report cleanup failure without losing the original cause, including falsey exceptions. Terminating this encoder is not terminating an accepted model's Native owner; no accepted-model preservation is inferred from realm loss elsewhere.

Result {version:1,unit:'millimeter',format:'3mf-core',mime:'model/3mf',revision,byteLength,parts:[{id,name,regions:[{id,bodyId,featureId,engine,engineRevision,materialId,appearanceId,objectId}]}],materialPairs:[{id,materialId,appearanceId}],buffer}. Small receipt at most64KiB; exact bytes standalone/nonshared up to64MiB. Output identity binds source revision + full captured part/region/source/material mapping. No native handle/token or hidden document mutation. No Blob/file/Save/browser/server commit receipt.

Initial reasons: INVALID_REQUEST, RESOURCE_LIMIT, SOURCE_BINDING_MISMATCH, UNKNOWN_MATERIAL_ASSIGNMENT, UNQUALIFIED_REGION_INTERFACE, UNSUPPORTED_MESH_DOMAIN, ENCODER_FAILURE, ENCODER_CLEANUP_FAILED; cancellation/deadline AbortError/TimeoutError preserve consumed-input state. Native/source authentication is upstream; errors must not imply invalid native geometry merely because encoding domain is unsupported.

Tests first freeze absence. Independent Python ZIP/XML/topology/analytic checks must inspect produced bytes/material/build associations. No UI/normal app/public3MF/Save/Open/slicer/physical print qualification. Full multi-region single-part acceptance stays OPEN.
