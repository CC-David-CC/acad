# Optional Core writer provenance, frozen before implementation

Approved addition to writeCore3mf(model,{signal,provenance}); absent provenance preserves previous XML and ZIP semantics. provenance exact {version:1,revision,parts:[{id,name,regions:[{id,bodyId,featureId,engine,engineRevision,materialId,appearanceId,objectId}]}],materialPairs:[{id,materialId,appearanceId}]}. IDs are bounded own-data authored strings, not native handles or caller resource ordinals. Crossbind parts to model.builds, regions to model.objects, pair IDs to model.materials in exact order, counts and associations, before async writing. Small ≤64KiB own-data capture.

One existing declared namespace metadata entry codi:ManufacturingBindings contains escaped JSON {version:1,revision,parts:[{id,name,buildResourceId,regions:[...saved region reference fields,meshResourceId,componentResourceId,materialResourceId,materialIndex]}],materialPairs:[...pair IDs,resourceId,index]}. Integer mesh/component/build IDs and material resource/index come from actual writer allocation maps only. Output mapping is independently XML-parsed and matched to actual resources/builds/materials. It is readonly provenance, never editable history or source authority. No ZIP reparsing/second archive encoding.
