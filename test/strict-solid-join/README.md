# Strict authored Join — component/protocol checkpoint

The existing WORKER_SOLID_BOOLEAN_V1 feature now captures and preserves kind:'join'. Only the private native invocation maps it to solid.boolean.union. Generic kind:'union' retains its earlier container semantics. No extra document, backend fallback, geometry healing or saved proof authority is added.

requireSingleGeometricSolid({engine,engineRevision,metrics}) classifies ALREADY AUTHENTICATED private-ledger observations. Standalone arbitrary JSON is not native proof. It verifies registered runtime/build binding, captures bounded own data without getters, and returns a detached frozen {version:1,policy:'single-connected-geometric-solid',engine,engineRevision,proof}. Physical material assignments and authored internal-region identities are not inputs and are never merged by this helper.

The ledger checks the postcondition after the actual mount result/selection/mesh and captured native metrics, before createModel, projection ownership, parent consumption or publication. Existing mount/result/operand identity checks remain. The same postcondition is checked again by the publication guard. A failed candidate closes its isolated evaluation owner; a separately accepted owner and its native resources remain intact.

Provider scope:

- OCC: native B-rep validity, positive finite native volume/bounds, one actual solid, and complete native topology census. A direct SOLID must have exactly its shell children; one-shell assumptions are forbidden. An outer COMPOUND/COMPSOLID is accepted only when its one direct child and wrapper census establish the sole solid, with no nested/extra/unaccounted wrapper claim. Multiple cavity shells are permitted. Legacy builds without these observations remain unqualified. This is existing kernel evidence for the bounded current unpartitioned geometric case, not proof of arbitrary self-intersection or future material-interface semantics.
- SMLib: level0/2 validity, native manifold predicate, one native geometric material region, finite positive native reported volume and known quality. Native void regions are allowed. NVIDIA materialRegions is a geometry census, not our physical material catalogue. Future deliberately partitioned multimaterial parts need their own connectivity qualification; this patch never erases their identities.
- Manifold: nonempty results remain JOIN_UNQUALIFIED pending the separate Worker proof extension. Actual cavity results have two boundary mesh components but one connected geometric material domain; component count or NoError does not establish the policy. This gap is not all-backend Join completion and is not reported as invalid cavity geometry.

Failure catalog: JOIN_EMPTY (verified empty), JOIN_MULTIPLE_SOLIDS (native multiplicity), JOIN_NON_SOLID (no volumetric solid), JOIN_NONMANIFOLD (native false predicate), JOIN_INVALID_TOPOLOGY (native invalid), JOIN_UNQUALIFIED (missing/inadequate proof). Malformed observations use ENGINE_FAILURE; runtime mismatch stays ENGINE_BINDING_MISMATCH/catalog revision errors. Ordinary kernel operation errors are preserved and never rewritten as mathematical impossibility.
