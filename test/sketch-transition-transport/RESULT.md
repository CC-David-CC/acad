# Internal sketch transition transport

Transport commits `5fbb260fe`, `3b913b264`, `4d6f7343c` plus test `1d93fd9e2` route only the two versioned transition tasks into the reviewed c9 headless core. The internal client snapshots bounded plain local-realm input, IDs, numeric external values and options before yielding; it uses the existing origin Web Lock, disposable Worker, deadlines and cancellation. It keeps a separate maximum-two transition budget through result validation, validates and copies/freeze-binds evidence, relation and error data, and checks lifetime/deadline during cooperative output UTF-8 validation. This does not publish a candidate or authorize a live edit; a future coordinator must independently verify its captured editor revision and lifetime at publication.

Input sketch text is limited to 1 Mi UTF-16 code units by this transport; exact 1 MiB UTF-8 input enforcement occurs in the Worker core. Output is checked to 1 MiB UTF-8 cooperatively before returning. A timeout is a rejected transport operation, not a solver inconsistency verdict. Returned evidence is bounded to the existing 10,000-row/100,000-residual limits and validated for dense own data, finite values, tolerances and units. Cross-realm callers must create local plain request data; exotic or accessor-based inputs are not accepted as the contract.
