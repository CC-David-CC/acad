# Detached sketch render records

`projectRenderSketch` is a pure Worker-side projection of an already validated native v3 sketch. It copies/freeze-detaches source and projected records; it does not instantiate a viewer, parametric manager or shape, reset or allocate IDs, validate a solve, certify provenance or publish a result. The caller must bind Worker result, source, revision and lifetime before use. Data returned across `postMessage` is cloned by the browser and must be validated/owned again on the receiving side; object freezing does not survive that boundary.

Each native object keeps ID, role and stage, with an analytic geometry record and existing descendant-point handles when supported. Canvas-compatible positive-direction arcs preserve major/minor/full sweep; ellipse display radii use the current shape renderer's `1e-8` minimum. Arc records also preserve endpoint and endpoint radius for the existing mismatched-radius cue. Bounds are finite conservative bounds of projected geometry, not measurement or a promise about omitted entities. `bounds.complete` is false when an object, generator or boundary is unrendered. Unsupported native types retain their exact copied source and explicit `geometry:null` plus an `unsupported` row. Stages/constraints/generators, boundary, dimensions and labels remain in detached `source`; missing generator geometry, constraint annotations, boundary, dimensions and labels are explicitly described in `unrendered`. They are not yet available for display or selection. BSpline and RigidGroup are retained but not rendered. This is not a complete legacy sketch viewer or claim of generic hit testing.

The prototype applies resource bounds of 10,000 objects, 32 stages, 100,000 visited values, 64 nesting levels and 1,048,576 accumulated source characters; refusal is explicit. These are limits of this projection path, not new native-document limits. It is synchronous and must run in its disposable Worker. Caller is responsible for Worker-owned validated JSON; arbitrary Proxy traps are not made safe by plain-object checks.

Run the pure controls with `node --test test/render-sketch-projection/projection.test.mjs`.
