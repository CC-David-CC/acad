# Bounded real-Worker spline Save validation — candidate

The headless solver admits saved B-splines only after data-only input preflight, before the real BSpline constructor's eager sampling. Each has at most 64 control, fit and closed-base points, degree at most five (interpolation is cubic), finite monotone valid knots, bounded exact child identities and ≤8192 conservative sample-work units across the sketch. The bound uses `spans * (2 + ceil(bounding-box diagonal / 50))`; it is an admission/cost limit, not a geometric tolerance or universal performance guarantee. Closed CV requires the explicitly authored base identities. Duplicate point IDs are permitted only inside one original list with identical coordinates, matching native IO; duplicate identities across separate lists and ambiguous representations refuse. Closed CV derived control/fit point IDs are not accepted as authored constraint targets; base-point identities remain addressable. Other unbounded/legacy ambiguous forms explicitly refuse rather than being repaired.

Using the existing real BSpline implementation inside the disposable Worker, the candidate independently reconstructs the spline's derived data before and after the actual headless solver. It reuses private EndPoints to preserve IDs and compares complete serialized data with absolute numeric tolerance 1e-9; changed/stale derived state refuses. Source bytes are never replaced by this check. Existing constraint admission, solver residual and strict identity validation remain in force. This is Worker geometry validation only, not an app/native/signed Save or every-constraint qualification.
