# Segment-length measurement roles

This bounded prototype converts a reference `LinearDimension` to a driving `SegmentLength` only when the reference endpoints identify exactly one current segment, its offset and measured length are finite, and no driving length already exists. The reverse requires exactly one accepted, nonredundant `SegmentLength` and no existing reference on that segment. Conversion retains the current physical geometry and the display offset; reversed reference endpoints invert the offset when mapped onto the driving annotation. These are different native objects: reference dimension IDs and transient constraint-annotation IDs are not claimed to survive conversion. Converting to reference removes the driving equation, including any expression it contained.

Promotion refuses already-proven locked-endpoint redundancy and rejected constraints; it does not claim general rank-based redundancy detection. The operation uses the existing sketch transaction and guarded single-use revision; if rollback is incomplete or unverifiable, it retains the pre-edit checkpoint as `recoverySnapshot` and blocks normal sketch history/save until explicit recovery. The shared snapshot guard and sketch history still serialize on the UI thread; performance and complete general mutation tracking remain open. This branch inherits the pre-060ee739 epoch hook; lead integration must retain the independently corrected 060ee739 rather than reintroducing the older hook.

The real-pointer control reproduces an adjacent measurement defect on the baseline: invoke Measure Distance, move to the midpoint of a segment, click, immediately move 20 screen pixels and click again. The tool is `drag` after the first click, with offset 0, empty pick arrays and no paint-populated scale; the move previously produced NaN, serialized as null. `LinearDimension.translateImpl` now waits for finite initialized pick geometry and scale before changing the offset. Existing nonfinite reference offsets are refused rather than silently repaired.

`test/webos/length-measurement-roles-browser.test.cjs` passes actual reference placement, contextual UI promotion, revision-bound demotion, strict native project reopen, sketch undo/redo, locked-endpoint redundant refusal, reversed-endpoint offset, invalid existing offset refusal, injected annotation/reference attachment failures, and explicit recovery after injected rollback and stage-rollback failures. The injected failures are controls, not assertions about actual kernel crashes. General point-to-point dimensions, ambiguous segment identity and other measurement types are unsupported by this conversion.
