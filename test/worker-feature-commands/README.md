# Worker feature command surface

`inspectWorkerFeatureCommands()` returns a revision, readiness/reason, millimeter/OCC operation availability and immutable bounded lists of current extrusion `{faceId,regionId}` and centered-hole `{bodyId,lidFaceId}` candidates. Availability means the named operation is registered and browser Worker/Web Lock prerequisites are present; runtime asset hashes and actual candidate geometry are checked when the operation runs. A four-boundary region is a candidate, not a claim that every such sketch is a valid XY rectangle. Native Mesh and cross-engine operands are not converted or advertised as OCC hole candidates.

`createWorkerExtrusion({revision,faceId,regionId,depth}, {signal?,valid?})` and `createWorkerCenteredHole({revision,bodyId,lidFaceId,diameter}, options)` call the same craft operations used by the modeler. All dimensions are finite positive millimeters up to 1,000,000. The caller cannot choose an operation name or feature ID, inject a native handle, supply publication callbacks or bypass craft. A successful immutable receipt contains `{featureId,bodyId,lidFaceId,unit:'millimeter',persistence:'volatile-workspace',revision}`; it is not a disk-save receipt. Stale revision, wrong target, unsupported engine and invalid input refuse. A current candidate's worker performs the actual sketch/solid/containment validation. The existing native document/history remains authoritative and the same atomic craft publication path handles failures.

The caller's signal and validity guard remain effective through publication. An internal scope records the exact craft evaluation epoch of the submitted command; an abort or invalid guard cancels candidates only if that epoch is still current. The interval and listener are removed on settlement. A late abort on an older completed command cannot cancel a newer operation. The guard reports `AbortError` on precommit cancellation and preserves an explicit `committed` indicator from the coordinator when present. It does not promise a hard real-time bound under browser background timer throttling.
