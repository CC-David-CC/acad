# Source-bound hole history integration checks

`history.test.mjs` runs actual detached authored-history capture, the shared
through-hole numeric journal and unrelated-sketch-save ancestry classification.
It verifies dimension-only proposals and exact edit travel, preserves descendant
intent, and refuses stale source/region/target/backend records. This is a pure
composition proof; it does not activate Craft, evaluate geometry, or save files.

Run `node --test test/through-hole-craft/history.test.mjs` (9 groups).

The production Craft hook is `authoredThroughHoleOperation`. It reuses
`authoredFeatureOperation` and the existing candidate/publication/journal
transaction. Center edits carry only diameter; corner edits carry diameter and
both offsets. Source and target bindings cannot be changed through this hook.
Typed/project parameter bindings are currently refused explicitly. Creation
undo/redo is a separate unfinished requirement.

Real app source/depth/edit/refusal/travel/Save/server-sync/fresh-Open qualification
is required before declaring this integrated workflow passed. Native component
geometry evidence lives in `../through-hole-browser/`; ledger transport doubles
in `../through-hole-ledger/` and focused journal controls in
`../through-hole-journal/` have deliberately separate claims.
