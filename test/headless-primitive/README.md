# Data-only primitive append prototype

`appendSketchPrimitive({revision,sketchJSON,externalParameters,primitive:{id,kind,role,stage,data}})` runs in a disposable Worker and returns either `{revision,ok:true,serializedSketch,evidence,primitive:{id,kind,role,stage}}` or `{revision,ok:false,error:{code,message}}`. It does not publish, open an editor, create history, or expose a public command. The internal ID must be a canonical `agent-primitive-<v4 UUID>` minted by the coordinator; validation alone does not authenticate its origin. The future public API must not accept a caller-selected ID and must bind source, frame, revision and lifetime before publication.

The source and result are each limited to 1 MiB in both UTF-8 and code units. Coordinates are finite local millimeters with absolute component ≤1e8; `role` is null or construction; only the current last existing stage is supported. Native constructors are `EndPoint` (Point `{x,y}`), `Segment` (`{a,b}`), `Circle` (`{c,r}`) and `Arc` (`{a,b,c}`). Segments and radii must exceed 1e-9, circle and arc radii are bounded by 1e8, and arc endpoint radii must agree within absolute 1e-9. Arc endpoints treated as equal by the editor's 1e-6 component tolerance are refused; use Circle for a full circle. Native arc order describes the counterclockwise start-to-end sweep, including major arcs. No coordinate snapping, coincidence constraint, contour closure, dimension, or profile repair is added.

The existing replay core first validates and exactly replays the input. The helper reconstructs a real `HeadlessSketchWorkspace`, checks coordinator ID and derived-child names against the native index and saved IDs, calls the real native constructor and stabilization in a model transaction, and strictly compares all previous native records after removing the one added object. The new primitive's own native data must exactly equal the constructor input. It then independently runs existing solve/domain/residual/generator checks and requires exact candidate geometry/intent equality. Missing-hint or otherwise unsupported source is refused by the existing replay validator. These controls establish a bounded native sketch transition, not a closed contour, CAD solid, frontend, or universally valid future solver result.

Actual strict-CSP Chromium tests use a separate disposable real Worker, genuine shape/constraint code, and the existing real `makeEmptySketch` frame constructor; there is no fake DOM, Canvas, window, history manager, or UI facade in the Worker. `browser.test.cjs` appends Segment, construction Point, Circle and Arc sequentially, checks exact old state and no invented constraints, major-arc endpoint order, a source with existing LockPoint, duplicate and child/boundary ID collisions, zero/invalid domain, near-full arc, invalid stage/ID, extra fields, overlarge UTF-8 source and exotic external parameters. `generator.test.cjs` appends to an actual captured two-Mirror chain and checks complete prior state plus generated-ID collision; source SHA256 `0d4626e416349a71d3f239f0d11b41a19e60cc91dc5466f67f35dda7f314a61c`. `scale.test.cjs` appended to a 512-segment/512-lock source in 2216 ms in one Worker run; this timing includes validation and is not a latency guarantee. Receipts are `receipt.json` and `scale-receipt.json`. `tsc --noEmit` passed. No cancellation/currentness or atomic history publication is claimed by this core.
