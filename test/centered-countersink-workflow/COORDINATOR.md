## Per-call Native transport

Private Native calls use only reviewed C ABI ports: Circle V3 constructor,
owned subtract/history, conical constructor/coupled read, topology/solid/census/
mesh inspection, point classification, exact-name release and owned-name count.
Scratch name bytes and F64 arrays are bounded, allocated before dispatch,
checked again afterward through current heap views and released once. No Native
pointer or name is returned to Main or persisted.

Temporarily replace ONLY the current actual global exchange receiver with a
store-only collector, capture its exact descriptor/identity, and restore/fence

ALL exchanges even if a positive record arrived first; new void conical ports
can throw their bounded error only after their private C++ locals destruct.
