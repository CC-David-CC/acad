# Explicit build selection for new generic parts

New OCC box parts now declare the same native-evidence build already selected
for new sketch-profile parts. This enables result qualification from actual
native topology/validity rather than relying on the older display-oriented
provider. The engine ID remains OCC; no SMLib promotion or backend fallback.

The registry retains exact historical identities. Existing ordinary AND empty
outputs/history continue their original build; this preference does not convert,
re-evaluate or relabel them. A new strict Join cannot treat an old result as if it
had gained unavailable native evidence.

Thirteen pure selection/catalog controls (three new, ten retained) and merged
TypeScript pass. These are selection contracts, not native Join qualification.
The next exact signed build must verify the newly selected runtime and actual
solid result before any acceptance claim.
