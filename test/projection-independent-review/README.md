## Confirmed defect and narrow fix

Before: `solve.ts` passed `c.write().constants` directly to its optional authored-evidence callback after checking residuals. `AlgNumConstraint` also retains that constants map from the native request. In a real solver Worker, the test-only trusted callback changes rect-0 SegmentLength to200. The solver returns ok:true, geometric length100 and saved target200; it also changes the native input map. The final intent comparison sees the same changed baseline and misses the mismatch. `callback-before.json` retains exact request/result/rows and Worker SHA `1b46f2130813f8f3c6f12fe26e8ee0f1b51aaa41d4665b2bc1c707a17ec7110a` (target E0EDBED002B70C81F8ECB1E57FF2DC36).

This is an injected mutation of the **trusted optional callback**, not a demonstrated ordinary-user or production-collector path. The normal collector only pushes rows. The installed runtime Worker3211 has no callback feature; the prototype was unintegrated during review.

Fix: `authoredEvidenceSnapshot` clones each bounded JSON row with structuredClone and recursively freezes the detached row, object-ID array and constants before the hook sees it (`solve.ts:147`, invocation at198). It exposes no c.write aliases. One-argument calls do not invoke this helper or add fields. The hook remains a trusted, synchronous internal API; this is not protection from arbitrary code that independently closes over and mutates its request.

After: the same real Worker fault control silently blocks the assignment, preserves input bytes, and returns ok:true with geometry100/target100. `callback-after.json` pins source d75, Worker `5f0ce0f8fb6a271e48adb5ff8172ebbd4d3dcacc9174eb9bda429d582041984f`, target9883E44369AA7F78BFB7473BD4BD2DF0. Source controls verify recursive freezing and detached nested values; the original input stays unfrozen.
