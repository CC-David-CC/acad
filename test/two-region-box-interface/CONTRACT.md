# Complete two-region interface workflow source contract

Approved source contract. No tests/builds, Native calls or services were run.
This branch starts from fresh independent ACAD history at
`14eea71`; it does not import the former repository's ancestry.

The first domain is one explicitly assigned printable object containing exactly
two current, untouched authored axis-aligned OCC boxes. Each region has its own
stable region/body/feature/material/appearance identity. Their open interiors
must be disjoint and their boundaries must share exactly one full matching
rectangular face. Separate printable objects keep existing semantics. No
curved, cut, holed or offset object is reclassified as an authored box merely
because its bounds resemble one.

## Private construction witness

The existing candidate ledger captures a detached box-construction observation
only when `kind:'box'` is genuinely evaluated and published by the registered
owned Native mount. It records the original authored origin/dimensions and
producer/backend identity from that captured intent. It is not a user-supplied
qualification flag, independent design model or saved metadata. The protected
discard-only observation reader checks actual private output membership and
emits this optional witness with that output's controlled artifact. The issued
batch and encoder metadata capture bind the witness to the same body, feature,
revision and artifact. Other operations do not inherit box authority.

The optional artifact field `sourceConstruction` is exactly
`{version:1,kind:'authored-axis-aligned-box',unit:'millimeter',engine:'occ',engineRevision,bodyId,featureId,origin:[x,y,z],dimensions:[dx,dy,dz]}`.
It is attached only by the real protected ledger observation path. Standalone
arbitrary JSON remains unable to authenticate Native membership: that authority
comes from the existing private candidate and issued-batch path, not from a
serialized witness claiming to be trusted.

There is no exported witness-creation factory. Only the actual ledger output
publication constructs the derived record; its shared helper merely captures
and validates bounded own data. Encoder capture strips the witness when its
body belongs to an ordinary single-region printable part, preserving that
existing transfer envelope. Multi-region requests bind the complete witness
in the existing bounded request binding. No Native binary/read protocol changes.

## Worker geometry and interface proof

All heavy work remains in the dedicated export Worker. Decode the exact issued
Float64/Uint32 controlled artifact once, preserving topology-based indices.
Verify the complete boundary is the actual constructed cuboid: finite bounded
coordinates, every triangle on precisely one expected oriented bounding plane,
all vertices in that face rectangle, and exact dyadic oriented area sums equal
to each of the six full rectangles. The existing complete embedding/manifold/
shell-orientation validator still runs on every region without exceptions.
These checks establish full cuboid coverage rather than trusting its AABB or
skipping intersections because two triangles happen to share a plane.

`captureFullFaceBoxInterface` returns only the constructor/surface/interface
observation, marked `requires:'per-region-embedded-shell-validation'`. The
encoder accepts an output only after `writeCore3mf` also completes its unchanged
full embedding/orientation checks for both regions. The intermediate receipt
alone is not an embedding certificate and is not persisted. Coordinate integers
are capped at1152bits; bounded triangle cross products/area sums stay below the
existing8192bit intermediate allowance. Cancellation/deadline checks run in the
Worker, with the existing dedicated encoder's overall deadline still in force.

Construction comparisons and region relations use exact Float64 dyadic values.
If an authored origin plus dimension cannot be represented by the actual mesh
boundary exactly, this bounded proof refuses; there is no tolerance snapping,
coordinate welding, silent recentering or invented physical-size accuracy.
Resource/deadline/bit exhaustion remains a resource refusal, not invalid shape.

For the two proven cuboids, compute the exact interval intersection. Exactly
one axis must have zero overlap at the opposing face, and the other two axes
must have identical nonzero intervals. This proves full-face equality, no
interior overlap, and connected geometric union. Matching interface triangles
may use different diagonals or vertex numbering. Neither region's mesh is
rewritten or welded; each material retains its closed oriented boundary, and
the 3MF has one build item grouping both explicit region resources.

Overlapping interiors, separation, edge/point-only contact, partial face match,
unknown construction, complex interfaces and more than two regions remain
typed unsupported/unqualified. Unchanged source identities stay distinct from
physical material definitions. Different explicit material IDs are required in
the intended first acceptance; the proof itself must not confuse material
names/colors with region identity.

## Saved intent and later expansion

The existing same-part grouping and named regions are already explicit authored
intent for this narrow two-box partition. The proof is recomputed after source
edits and fresh Open. No redundant persisted `interfaceProven:true` flag or
transient face ordinal is introduced. A response-local derived method name
`full-face-box-adjacency-v1` may describe the actual successful proof. General
inset labels, partial interfaces or multi-material physical modeling will need
a separately versioned domain/relation contract; this slice does not qualify
those future operations.
