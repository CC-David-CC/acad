# Worker manufacturing save preparation

Source `672aa235` preserves the existing native envelope, geometry revision and manufacturing digest domains. One detached native snapshot is captured, then canonical fragments are bounded and sent to a dedicated hash worker; the 8 MiB preparation limit remains. `prepareHostSave({signal,valid})` returns `{envelope,isCurrent}` for the current operation; `isCurrent` becomes false on document, caller, workspace, craft, material, expression, surfacing, workbench or assembly change and is not a persistent dirty-baseline token. `snapshotForHostSave` delegates to it. Rebind confirmation uses the same guarded capture. Snapshot creation, legacy restore and the desktop's final JSON serialization remain main-thread work; this is not a 128 MiB or full worker-serialization claim.

Node regression compares the two resulting hashes to the legacy implementation, rejects stale/cancelled work and enforces the cap. A 4 MiB synthetic Node baseline on this workstation required two legacy captures and took 131 ms; it is not a browser responsiveness measurement. Real Chromium + OCC test `worker-save-browser.test.cjs` passed worker cancellation, in-flight history-change refusal, a dimension edit requiring rebind, native replay, and operation-token invalidation. An early run hit the old served bundle while webpack was still running (`prepareHostSave` absent); the completed build passed.
