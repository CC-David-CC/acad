# Saved-sketch DXF coordinator

`guards.test.cjs` evaluates the real coordinator with controlled services and Worker replies. Sixteen controls cover discovery, no source write, source/key/namespace/document/frame/face/model/epoch/parameter/stream/busy/editor changes, callback cancellation and option accessors. These are controlled guards, not a browser integration or a real Worker lifetime test.

The test-only strict-CSP Worker built from this branch was exercised in Chromium with the existing independent group-code tests and a same-frame changed-boundary refusal. Worker SHA-256 `87057f07c6caa686ab98817b52fab986139b1982c5ea40d41ccf522995faed97`, verb SHA `55f13091a656c635d1ebe3931a9b52236c65023549b7b69bc8278362f87686f3`. The saved sketch and current face outline are compared inside that Worker; the actual current boundary extraction is performed once from the live face on the main thread. The scope excludes actual Files writes, production Worker dispatch wiring, and an actual app host-lifetime/cancellation test. NURBS and sketch annotation export remain explicitly unsupported.

An outline-only follow-up admits a current, registered planar face with no saved sketch. The private Worker receives `sketchJSON:null`, constructs its empty native model in its own realm and exports the captured current analytic boundary; it does not write a sketch. Discovery is bounded to 64 candidates and 1,024 visited model faces. Three further controlled tests cover null-source discovery and no write, rejection when a sketch appears mid-export, and nonplanar/worker-owned exclusion. A real strict-CSP Worker run and independent group-code inspection verifies one line, one circle and one arc with no ground point, while the saved-sketch boundary mismatch control remains.
