# Public accepted physical quantities

Source preparation only until a complete actual browser workflow and independent
saved-file checker pass. No component tests or seeded successful geometry.

The inspector projects the already accepted Worker result as detached
name/dimension/value/unit rows. No formula evaluation or second quantity table
is introduced on the UI thread. Currentness and document guards remain.

The complete workflow authors and binds the normal selected rectangle/five-bore
part, then adds2in/1in²/1in³/90deg, derived area/volume, length ratio, integer
count and boolean definitions. Canonical values and real Native measurements
are checked independently. Invalid dimensions, unknown unit/name, overflow,
zero division, fractional/dimensional count, invalid boolean, cyclic reference
and comma-call syntax refuse without durable change. Real UndoRedo proves the
refusals add no authored entries. Only the four already qualified opaque
host/physical/journal/solids inspection revision tokens may refresh on refusal.

Inch display preserves physical geometry. Native Save/browser commit/server byte
sync/fresh Open retains definitions and values. Width inch(4) drives101.6mm
geometry; equivalent mm(101.6) spelling preserves size while retaining authored
intent. Three native files include reopen/reedit/travel and separate display-unit
changes. Independent arithmetic/source checks follow the whole run.

This does not qualify arbitrary typed geometry, mass/density, rendered labels,
configurations, material uncertainty or manufacturing tolerances. Run the driver
with normal signed harness environment plus CODI_ENGINE_REVISION on a frozen
composed runtime, then run python3 check.py EVIDENCE. Keep all first failures.
