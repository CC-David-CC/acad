# Closed sketch coordinator prototype

`closedSketchTransitions.ts` is a private craft factory with bounded face discovery, async Worker-backed inspection and LengthRelation preparation, and a private exact-byte journal travel callback. It does not expose source bytes or publication hooks to callers. `inspectSketchTransitions()` returns `{ready,reason,revision,candidates:[{faceId}]}`; `inspectClosedSketch({revision,faceId},options)` returns the inspected frozen worker discovery; `applySketchLengthRelation({revision,faceId,ids,factor,offset},options)` proposes a full candidate replay and returns an authored-undo receipt after publication. Source sketches remain bounded at 1 MiB; the existing journal's aggregate budget still applies.

Only current open-plane faces and consumed source faces named by a unique supported `WORKER_RECTANGLE_EXTRUDE_V1` operation are discoverable. The existing strict history allowlist checks every operation; unknown or implicit consumers are refused. A consumed face may have multiple prior planes: its exact original face/plane is authenticated by the candidate replay's required `sketchSourceFrames:[{id,frame}]` check before consumption. Saved nonempty boundaries, missing/stale frames, unqualified typed parameters, active sketch editing and stale full-tip state refuse. A generic journal travel verifies both stored endpoint frames and uses the replay Worker to validate the exact target bytes. The candidate source override is read-only; `storage.prepareWrites` and the private `sketch-bytes` intent are handed to the existing craft replay/atomic publication. Exact frame/plane checking in that evaluator and its registration of this factory remain integration requirements.

`coordinator.test.ts` bundles the actual coordinator with synthetic data-only service and Worker stand-ins. It tests immutable ID/revision discovery, accepted staging, current and consumed source, more than one plane, unknown consumer refusal, active editor/typed refusal, source-key and epoch changes during a held Worker, document cancellation, abort synchronously inside `valid()`, stale frame, exact private travel and precommit-vs-committed lifetime distinction, plus reentrant editor opening after commit with `committed:true`. The stand-ins do not establish geometry, actual Worker, candidate pipeline, UI or native Save/reopen behavior. Run `CODI_CLOSED_TEST_OUT=/tmp/private-tests node node_modules/webpack/bin/webpack.js --config test/closed-sketch-transition/webpack.cjs && node /tmp/private-tests/test.cjs`. `tsc --noEmit` also passed against parents `a42a81c89` and `467a145c1` (cherry-picks here `edc5b4a94`, `83b6f3ecc`). A production registration, real downstream model replay, true undo/redo, held-worker cancellation, frame mismatch, mutation race, currentness/reentrancy and native Save/reopen require the integrated real browser tests; the coordinator alone is not an agent workflow or proof of responsiveness.
