# Enclosure material assignment candidate

The shared project manager operation assigns explicit BODY and LID bindings to separate printable objects. Material identity and appearance identity remain independent; editing an existing object preserves its name, region ID and transform. Discovery issues a revision tied to document, craft, storage and material changes, and assignment rechecks lifetime and the exact live pair around cancellable hash work. The UI and host-facing operation use the same assignment implementation. A SHA-256 worker receives bounded canonical batches; the existing native snapshot/save/restore path still performs main-thread serialization and hashing and retains its 8 MiB research cap. The experimental Merkle cache is not used because its required trusted per-item lineage is not established.
