## One accepted source and independent proof workspaces

Normal `IO._loadSketch` still validates, decodes, finishes admission and refreshes
as before. Its existing decode body is extracted once. A new internal synchronous
headless evaluation entry consumes a fresh workspace's private WeakSet authority;
there is no public `skipSolve` request or normal loading option. It never calls
finish/prepare/solve, never publishes a model, and clears the one-use workspace.
Actual constructors/stabilization reconstruct original objects, owned children,
Polar/ArcConsistency, stages, annotations and generator references. Exact native
serialization is checked before and after evaluation; constructors cannot silently
repair captured geometry. Worker termination remains with the existing client.

`sketchValidation.ts` contains the same preflight and original registered
constraint-domain/residual loop used by normal `solve.ts`. Captured evaluation
resolves actual constants, checks all finite parameters, source/stage/parameter
ownership, directional and rigid domains, intrinsic equations, fixed boundaries,
Mirror outputs and spline geometry. Current original-equation tolerances remain
1e-6 mm / 1e-8 rad by registered schema; they are residual checks, **not** a
retained-source equality relaxation. Its quality is `validated-captured-equations`,
not successful optimization.

Append parses the ORIGINAL request and checks the fresh coordinator ID and all
child IDs against the complete retained data/reference inventory. Only the new
primitive is placed in an ordinary production solve workspace. Its actual solved
serialization must equal requested geometry/identity; it has only its own expected
intrinsics and no authored constraint, generator or external object dependency.
That solved primitive is appended to the unchanged captured source. No old object
is reserialized from a post-load/optimizer model, and no old coordinate is copied
over a changed or failed solve result.

The FULL candidate still cold-solves independently. Its actual authored
accepted/redundant classifications must match every retained row exactly. The
existing complete intent, original residual, replay displacement and directed
branch checks remain mandatory. The optimizer's geometry is proof-only and never
published. A separate fresh decoder validates the FULL candidate's original
equations at its captured coordinates with those fresh classifications. A failure
of either proof refuses the transaction. Saved admission is priority metadata,
not an authorization to skip fresh classification. The returned residual evidence
comes from the captured candidate, paired with actual cold classifications.

A second genuine Worker recomputes the entire append from the original request;
it compares full candidate bytes before the existing guarded prepared source
replay, journal/publication and lifetime path. No new history, persistent cache,
Native capability, PM/Craft/AlgNum/Isolation change or Native geometry claim.
