# Source-bound through-hole ledger checks

Protocol and projection doubles replay the pinned genuine Chromium geometry in
`../through-hole-browser/evidence-r1/through-hole.json`; they do not execute a
native runtime, Worker, browser, app history, or file save. Float32 preview bytes
are generated from recorded Float64 coordinates for protocol checks only.

Run `node --test test/through-hole-ledger/ledger.test.mjs`.

The three full chains check shared custody, source handles surviving consumption,
real source face/region/feature binding, one inherited origin, and fillet/chamfer
continuation. Controls reject stale or absent bindings, changed source planes,
consumed target reuse and invented tool origins before publication. Original
selected-profile and Boolean ledger controls must continue passing separately.
