# Standalone drilled model prototype

This is an explicitly unbound, nonpublishable scaffold over a sanitized real OCC standalone BOX-cut response (`fixtures/standalone-box-cut.json`, SHA-256 `ae77e1e6bc0dde42a95b4d9a8c9e14989f56079e916d0f97acff0486c737094d`). It does not prove authored-parent provenance, semantic roles, kernel history, current mount, registry safety, or suitability for any app operation. The later adapter must use a strict checked authored-worker response and owner-bound association. All prototype identities are transient and use the existing guarded `worker-prism:1:` namespace.

`assembleBoundedDrilledSolid` assembles a model with analytic circle/cylinder data and the native planar/cylinder display triangles, two planar circular inner loops and the repeated same-face seam. A fixed 64-segment sample is used only by the prototype's circle display tessellator; the analytic curve remains the CAD representation. It does not establish manufacturing-quality tessellation or adapt generic CAD consumers. In particular `Loop.isCCW()` and `MBrepFace.getBounds()` use start vertices, so one-edge full-circle loops need a separate analytic treatment; do not treat either helper as a valid circular boundary oracle. Curve split/transform/degree and cylinder transform/degree remain unsupported.

Serve the resulting `worker.js` as `static/drilled-projection-worker.js` in the loopback strict-CSP engine fixture described in `test/engine-extrude/README.md`, then run `JSKETCHER_TEST_URL=... CODI_TEST_CDP=... PUPPETEER_CORE_PATH=... /tmp/codi-files-move-node/bin/node test/engine-hole-projection/browser.test.cjs`. In the recorded run, a real Chromium dedicated Worker had no DOM/Verb and assembled 7 faces, 15 edges, 10 vertices, two circular inner loops and one cylinder seam with opposite half-edges; five malformed inputs were refused. This test consumes a retained native probe response and does not run OCC inside the projection worker. It is not authored-worker, rendering, history, save/reopen, or end-to-end hole evidence.

The same projection test also consumes two retained **authored-prism worker** cut responses (`fixtures/authored-worker-results.json`, SHA-256 `d913fe295954f55689f8065a8fc9310f6d3fee2db2252fd5a48221a70638524c`). They represent 100×50×20 and 150×30×35 mm translated parents with diameter 10 mm. The test checks the actual projected rims move with the changed center and have matching topology. These responses came from a separate research worker run; the projection test replays their retained data and does not itself verify worker ownership, provenance, full solid validity or atomic publication.

`drilled-role-mapping.test.mjs` exercises the proposed same-cut parent/cutter history shape, including retained authored-worker results (`fixtures/authored-worker-history-results.json`, SHA-256 `d140c4d0bab708bb3b0c301d1befad1ef89e3c0095646d6b4e7d78c0f104e64a`). Its parent role labels are supplied by the test and are not evidence of parent-index-to-authored-role binding. `deriveDrilledRoles` requires the caller to establish and authenticate that mapping and the exact worker snapshot. It provides local role assignments, never persistent IDs. Missing or ambiguous histories, conflicting rim ancestry, duplicate descendants, malformed seam/twins and accessor fields are refused.

The experimental checked projection combines role mapping with a drilled-model mutation invariant and an adapter using the candidate ledger. Its present isolated tests use fabricated parent-role labels and retained worker output; they do not authenticate a live mount or prove the index-to-role mapping. The adapter must not be registered or deployed until an actual combined-worker run and independent review pass. The model includes explicit display polylines for all edges for the existing edge-view path, while analytic geometry stays authoritative. Publication checks are returned to the history factory, which must register them; the adapter does not register them itself.

It compares all six parent/descendant face semantic IDs, outward analytic normals, support planes and outer bounds; checks center/rims, model counts, face-view BufferGeometry construction and outward display winding; and verifies pre-abort, closed-owner and post-registration vertex-mutation refusal. Faces inherited from the consumed parent retain IDs; unproven parent edges, vertices and the seam do not.
