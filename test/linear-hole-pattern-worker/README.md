The Worker initializes bounded private state only for an actual source constructor. Qualified edge-treatment results carry that state only after native success. The current target must own one exact successful centered witness matching seedFeatureId and the live actual source constructor/build. Witnesses contain metadata, not native seed handles or duplicate saved models. States/records are bounded (32 feature IDs,16 known hole witnesses, at most the bounded result set) and disappear with disposal/Worker closure.
