# Common solid-output history control (prepared)

`output-history-browser.test.cjs` is a prepared registered-core agent test. It has **not passed** on the upcoming combined source yet. Set `JSKETCHER_TEST_URL`, `CODI_TEST_CDP` and explicit `CODI_TEST_SOLID_ENGINE=occ|manifold|smlib` for an isolated direct fixture. It depends on the reviewed output contract: stable `outputId`, `bodyId:null` for empty, `inspectWorkerSolids().outputs`, same-engine Boolean inputs and model-local `volumeMagnitude` where a valid closed result has a volume.

It constructs disjoint box intersection to produce an empty output, reuses it as a Boolean operand, edits the upstream box so that the intermediate result becomes nonempty, checks dependent volume and stable output identity, rejects a negative dimension without changing the native snapshot, uses the shared authored undo/redo and restores into a fresh context. Independent separate disjoint and edge-touch union projects are also saved/replayed. Edge-touch classifications are reported rather than forced to match across kernels, and a nonmanifold nullable volume is not silently made zero. The test checks no handle or derived metrics appear in authored native history. No signed Files, desktop host command, physical printing or general cross-engine geometry equivalence is claimed.

The control must run on the exact matched app/Worker/catalog build. Raw SMLib result/catalog work is still pending at preparation time; a missing capability or unsupported kernel result is a failure/limitation to record, not a reason to substitute a different engine or omit the case.
