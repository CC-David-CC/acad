## What changed

The existing bounded history classifier now recognizes exact known generic
BOX/SELECTED/BOOLEAN records. BOX has eleven fields, SELECTED nine, BOOLEAN
eight. Every required field is own enumerable data, with exact counts and
literal versions/units, bounded numeric domains and registered engine builds.
Selected profiles require the qualified selected-profile build; unknown hashes
do not become trusted runtime identities merely by matching a regex.

A historical feature map reserves IDs permanently. A separate live generic
output map uses the existing canonical solidBodyId function. BOX has no source
faces; SELECTED records its explicit source face; BOOLEAN unions both parents'
source sets, consumes their live IDs and creates its own output. Unknown,
forward, repeated, reused-consumed or mixed-build/engine parents refuse.
The generic ledger's one-engine/build rule remains enforced. No region/face ID
substring heuristics, native handles or geometry are used by this classifier.

Empty Boolean outputs retain dependencies: changing a source can turn an empty
result into a solid. Related in-place fast saves still refuse. Sentinel and
unrelated-source queries may admit known ancestry, but actual closed-source
changes continue through the existing full atomic candidate replay, genuine
Workers, frame/region validation and publication. Unknown schemas still refuse;
the old plane/enclosure/rectangle/hole checks remain unchanged.

appendClosedSketchPrimitive, selected-region discovery/extrusion, generic
Boolean and diameter commands. Returned IDs/revisions are used. No native
authoring seed, private wizard, raw history/source writer, alternate renderer

generated by normal prepareHostSave after public authoring; it is persistence
validation, not a file seed. Signed My files/account integration remains a
separate previously accepted proof.

The main circle-union case starts with two radius10 circles at x0/30 in one
source sketch, extruded5mm. D24 changes the first radius to12. D70 on the other
circle is a valid scalar and circle, with no previous conflicting driver; its

refusal is not mathematical inconsistency or a native Boolean kernel failure.
These diameter commands add the first driving constraint to each literal
circle. Replacing an already-authored driving dimension is a separate API/
qualification concern; this proof does not silently turn addition into editing.

The empty-to-solid case uses two separate one-circle source planes, avoiding
unsupported intersecting loops within one sketch. After common produces a

30mm apart. Independent circle-intersection area times5 verifies its volume.
