# Inset-label paired interface qualification

`mount.readEnclosureInterface({op:"solid.enclosure.interface",version:1,body,lid,label,maxDeviationMm},{signal})` requires the exact live, same-mount private v2 triple and captures handle values before awaiting. It reads and qualifies both actual manufacturing meshes in the worker, which retains bounded private copies. The worker requires all three records to belong to the same operation and combines their bounded common-volume result with five actual opposing interface surfaces. For each surface, existing per-role coverage/winding checks apply; their projected triangle areas and the containing expanded rectangle give a conservative positive lower bound for shared projected area. The combined spread of actual plane coordinates must be at most the requested tolerance. The finite, frozen result reports `version`, `quality:"paired-planar-contact-v1"`, `roles:["LID","LABEL"]`, `unit:"millimeter"`, `maxDeviationMm`, `commonVolume`, `surfaceCount:5`, `maxSeparationMm` and `minSharedAreaMm2`.

This is tolerance-bounded geometric evidence in the common worker coordinate frame, not a claim of exact coincidence, printer fit, adhesion, manufacturing process or physical testing. The consumer must bind this exact feature/triple to its current authored revision and require the LID and LABEL transforms to be identical. No native pointers leave the worker. A 128-triangle limit bounds worker geometry processing; only structural and ownership checks run on the main thread.

`prepare-contact-fixture.cjs` creates isolated no-blob CSP fixtures from the exact pinned OCI and Manifold runtimes used in LABEL-RESEARCH.md. `label-contact-browser.cjs` uses a loopback fixture on 19976 and Chromium CDP 19965. Actual strict-CSP browser runs for both engines pass 100×70 and 120×70 cases with a 40×20×1 inset: five interface surfaces, zero common volume and measured maximum separation zero at requested 0.001 mm; conservative minimum shared area was 19.957996 mm². They also exercise cross-mount/missing/closed/disposed handles, capture despite caller mutation, canceled manufacturing read with independent mount surviving, and malicious result rejection/worker close.

For the negative, the fixture deliberately substitutes a real label translated five millimeters above the lid after the original common-volume check. Thus the saved common result remains zero but no longer authenticates the substituted disjoint label; the worker must reject the displaced actual mesh and close before producing an interface. A second synthetic control shifts an already qualified mesh and verifies the interface routine refuses it. Neither fault injection asserts that a generic native cut always returns valid provenance.
