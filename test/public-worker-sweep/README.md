# Public sweep source discovery and command boundary

This component uses real production sketch-solver and semantic Workers. It does **not** publish a native sweep, mount the desktop application, author successful model fixtures, or qualify Save/Open. The submission double always rejects `NATIVE_NOT_RUN`. Root must compose and qualify the normal application separately.

The four methods are `inspectWorkerSweeps()`, `inspectWorkerSweepRegions({revision,faceId,pathFaceId,engineRevision},options)`, `createWorkerSweep({...},options)`, and `inspectWorkerSweepHistory()`. Options contain only optional `signal` and `valid`. Discovery is available on an eligible empty document; source planes are not a readiness precondition. A write requires two distinct current saved independent source planes, one explicit sweep-capable build, and capacity in that complete authored part.

Creation takes exact fields `revision,version,unit,engine,engineRevision,faceId,regionId,pathFaceId,pathCurves,transport,bodyPolicy`. Version1, millimeter, OCC, corrected-frenet, separate are explicit; path references are ordered `{curveId,reversed}` data. The application allocates `featureId`, saves the existing canonical eleven-field intent, and submits the existing operation. Successful publication must retain both source planes and one measured valid native solid of the requested runtime. This test does not fabricate such publication.

Region discovery returns `revision,faceId,pathFaceId,sourceDigest,pathDigest,engine,engineRevision,unit,regions,pathCurves,qualification`. Profile region rows retain the existing support/reason/outer-and-hole local curve-ID descriptor. Path rows identify actual source objects using `curveId,type,role,stage,supported,reason`; supported Segments/Arcs expose actual `a,b` and Arc `c` coordinates. Unsupported candidates remain rows with reasons. There is no guessed path ordering, direction, shortest-Arc branch, attachment, transport, native-validity, or successful creation claim in discovery.

The Worker captures, hashes and parses each source once, then inspects the captured inventory. Both frames/strings detach before digest suspension. Sources, source candidates, path refs, and UTF-8 response have explicit bounds; oversized output refuses `RESOURCE_LIMIT` without truncating opaque identities. Global unsupported profile topology keeps existing errors. Path source stage/generator/domain admission remains unchanged; candidate support is membership-only. Source equality is namespace-versioned as well as byte/frame-bound, so ABA changes refuse.

The command performs two independent reconstructions of each source and two independent semantic inspections, validates returned source bindings/region descriptors/candidate inventory/coordinates, then compares both results. This is response corroboration inside the trusted application, not a standalone native proof from arbitrary JSON. A profile/path source snapshot belongs to one captured project generation and service/stream set; closure, source changes and currentness failures dispose pending Workers. Readonly discovery remains possible at native result capacity.
