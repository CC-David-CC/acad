# Complete typed part artifact workflow

Source-ready, unexecuted. This slice admits only the existing qualified modern
selected canonical rectangle, extrusion and source-matched through-hole typed
family to the three existing artifact readers. It uses the actual accepted guarded
expression service, unchanged shared observation replay and strict numeric Native
requests. No new facade/state/ticket, Native/ledger/Craft/PM/encoder/desktop change.

`desktop-driver.mjs` is one full public workflow using the exact on-disk public
`source-bound-parameters.mjs` recipe. It does not alter the passing E18 driver.
It builds and binds width100, height=width/2, depth=width/5, hole=width/10,
corner=hole*0.4, offset=width*0.08; genuinely assigns PLA/Blue to the discovered
final output and authors a linked three-view/six-dimension drawing using actual
source IDs, Native cap selection IDs and the centered-hole feature. It saves the
editable Native v3 document and exports STEP, core 3MF and SVG through normal My
files commands. Files must synchronize to the owning server account before their
actual bytes are captured. No raw successful model seeds or fabricated replies.

Width120 then drives actual geometry. Stale STEP/SVG requests and current 3MF with
unreviewed old assignments must refuse without writes. Actual Undo/Redo afterward
proves failures did not add a journal entry. Material review uses genuine public
propose/confirm commands; no automatic rebinding. Inch display preserves physical
mm and derived artifact units. The workflow exports an edited set, saves/opens,
exports a reopened set, reedits width130, reviews, exercises mixed formula/review
travel, exports a reedited set, resaves and opens again. Three actual Native saves
and twelve real artifact files are expected. Every successful read compares exact
accepted source/history/metadata/association/counters/resources before and after;
refusals normalize only opaque inspection tokens and still compare real journal
content plus subsequent ordinary travel.

Build selection remains explicit and unchanged across the part. The supplied
`CODI_ENGINE_REVISION` must already stage through holes, point reads, STEP,
controlled manufacturing mesh, Native drawing references and HLR projection.
There is no per-feature fallback/conversion and no default change. Other typed
feature families remain unsupported. All previous bounds/cancellation/cleanup/
assignment completeness/Native measurement equality and account/file guards remain.

After the ONE complete application workflow, run `check.py EVIDENCE
--desktop-source DESKTOP_SOURCE` once. It imports no production validator. It uses
standard-library JSON/XML/ZIP parsing and the retained independent mesh arithmetic
oracle (its source hash is pinned in the workflow). It checks saved authored
definitions/bindings/source geometry, real reference IDs, materials/color/units,
ZIP CRC/resource/component maps, closed oriented five-bore meshes and independent
analytic/mesh material and void observations. Tessellation error is explicitly
bounded separately from exact Native volume.

`step_oracle.py` is a deliberately narrow independent STEP21 analytic/topological
reader for this actual planar plate/five straight cylindrical through-bores. It
checks the real manifold shell, six planes, five inward cylinders, cap rectangle
and circular loops, rim/seam membership, units, bounds and independently derived
analytic volume/material. It refuses other curve/surface/topology forms. This is
not a general STEP importer, arbitrary-kernel validity proof or external CAD/slicer
interoperability claim. SVG XML checks distinguish solved/native dimension facts
from derived sampled presentation paths and validate actual document/geometry
tokens, labels, reference roles and three view transforms.

Required runtime variables are the normal signed harness variables:
`CODI_DESKTOP_SOURCE_ROOT`, `CODI_SIGNED_PINS`, `CODI_EXPECT_SOURCE`,
`CODI_EXPECT_DESKTOP`, `CODI_ENGINE_REVISION`, `CODI_TEST_URL`, `CODI_TEST_CDP`,
`PUPPETEER_CORE_PATH` (24.35.0), and a fresh `CODI_EVIDENCE` directory.
No isolated tests, probes, builds or browser runs accompany this source checkpoint.
