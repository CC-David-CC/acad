# SMLib Worker research mount

`createVerifiedSmlibMount({workerUrl,wasmPath,timeoutMs})` provides the descriptor/ready/execute/close protocol, synchronous `assertSolidBinding(handle)` and `readSolidMesh({op:'solid.mesh.read',version:1,handle},options)`. Box/Boolean/dispose use existing versioned millimeter requests. Mesh is expanded Float64 triangles, `display-only`. Boolean copies both operands before the mutable native API. Two authored boxes with disjoint or touching bounds for common and two identically authored boxes for subtract are proven zero-volume and refuse with `EMPTY_OR_NON_SOLID_UNSUPPORTED`; other native failures report `ENGINE_FAILURE`. Both close the candidate Worker. No empty-solid identity is invented. Host must pin bootstrap bytes; Worker checks WASM SHA-256. Handles are transient and same-mount, never saved. Volume uses `SmApiBrepComputeVolume` tolerance 1e-3; no general analytic topology, manufacturing accuracy, STEP, extrusion/history or cross-kernel equivalence is claimed.

Lifecycle follow-up: mesh is also dispatched through `execute`; binding refuses while busy or closed. Monotonic deadlines reject responses processed after expiration, including a blocked main thread. Failed/busy requests do not consume lifetime slots. Mesh reads compare fresh volume/bounds with the private creation evidence before return. `test/smlib/lifecycle-browser.test.cjs` uses a protocol-only Worker double to exercise timeout, injected messageerror, busy-budget, request mutation and evidence-mismatch controls; it is not geometry evidence. The real strict-CSP Worker controls remain separate.

Cancellation control: `test/smlib/microtask-cancellation-browser.test.cjs` uses the actual strict-CSP Worker to abort in the microtask between readiness and dispatch for box, mesh and disposal. All three reject `CANCELLED`, send no operation message, and preserve any existing binding. An instrumented response delivery also aborts after the real native operation completed but before the caller continuation; the candidate closes and returns `CANCELLED`, with no handle published. The latter does not claim the native operation did not run.
