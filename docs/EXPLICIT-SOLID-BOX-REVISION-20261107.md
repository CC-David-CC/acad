# Explicit first-box runtime selection

The shared createWorkerSolidBox request accepts optional engineRevision as an exact registered sha256:JS:WASM identity. This enables a new empty part to start on an explicitly chosen capability cohort, including the forthcoming owned-shell cohort. Omitting it retains the declared default for a new part and continues an existing part. Providing it must match all existing outputs/history; no silent substitution or conversion is allowed. Registered identity does not prove assets are installed: the real mount still owns availability and initialization.

The admission budget is derived from the actual history and selected requested build. The previous displayed/default empty-workspace budget must not reject a different explicitly selected build before evaluation. Request own-data capture, signal/lifetime/currentness, complete candidate replay, native resource ownership and shared history publication remain unchanged. Unknown/malformed/mismatched revisions refuse. Public descriptor exposes the optional field; no saved schema changes.

Source-only until composed shell application acceptance. No per-step tests, default promotion or old-part migration.
