## Source of truth

Saved intent has exactly eleven fields: `version`, `unit`, `engine`,
`engineRevision`, `featureId`, `faceId`, `regionId`, `pathFaceId`, `pathCurves`,
`transport`, `bodyPolicy`. The path is an explicit ordered list of actual local
source IDs with a boolean `reversed`. Coordinates, solved hashes, frames,
tessellation, handles and native topology stay out of saved parameters.

Evaluation captures both genuine sketch-solver results under one owned project
generation. The new Worker semantic seam verifies each serialized source hash
and boundary frame and corroborates selected membership. Both mutable inputs
detach before either digest suspends. Matching revision strings alone do not
prove document ownership; the eventual shared operation must retain the caller's
generation, service, stream, frame and source-currentness guards through publish.
The bounded path source is at most64KiB UTF-8; hashing/preparation belongs in a
Worker, with no file-sized main-thread processing.

`SolidKernel` receives an ephemeral `solid.profile.sweep` version1 request with
one depth-free selected profile and a separately framed path. It preserves raw
source Arc endpoints/center. Source Arc `a→b` means its CCW branch; reversing
traverses that same branch backwards. No shortest-arc substitution. The existing
document full-Arc rule is strict `abs(dx)<1e-6 && abs(dy)<1e-6`; this first slice
refuses that closed path explicitly. Exact connectivity does not weld nearby
endpoints. Circle/Segment profile membership uses the existing region extractor.

Transport is explicitly `corrected-frenet` with no added twist. The native path
payload is `[1,0, origin3,x3,y3,z3, count, records...]`. Segment records are
`[0,au,av,bu,bv,reversed]`; Arc records add center coordinates after `b` and use
kind1. The real native contract must verify placement, G1/path support and valid
positive-volume single-solid output. A prepared request is not a valid solid.

Path start must lie in the profile plane and the directed initial tangent must
be parallel or antiparallel to its normal. There is no origin/centroid equality
requirement, implicit move/rotation, scaling, invented extrusion depth or prism
provenance. Broader off-center profiles are real sweep inputs even where a
particular independent oracle or first native slice does not qualify them.
