# Native source adoption before publication

Full-tip candidate replay requires every actual saved sketch ID to have been read and adopted by a recreated owning non-Worker face. Private registry coverage retains successful adoption even when later features consume that face. Merely finding a key, guessing a source ID or seeing a final face is not evidence. The check runs after final candidate registry flush and before resource sealing/accepted publication. Prefix rollback skips completeness because future sources legitimately remain for Redo. No new model, source format, migration mapping or geometry parsing.

Registry codece8f1f51f captures a bounded dense primitive ID inventory and throws UNRESOLVED_SKETCH_SOURCE. Shared native Open preserves the pipeline code/message while the existing restore transaction owns rollback. This rejects unmatched keys instead of opening an empty recreated plane and silently orphaning saved geometry. Actual consumed/attached source domains remain supported without assuming every source is independent.

Source integrated; complete native Save/Open and unmatched-source rejection require a composed build and whole workflow. No filesystem race/security probes or per-step tests. E19 R4 PASS predates this guard and is not proof of it.
