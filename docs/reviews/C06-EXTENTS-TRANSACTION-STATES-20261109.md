Source preparation only. The extent operation, service and capability remain unregistered/disabled while reader, source-parent, persistence and public transport seams close. No execution, qualification or general precision claim.

Caller AbortSignal state and listener operations in the new service use the actual native intrinsics. Setup attempts are recorded before listener calls; cleanup attempts every owned removal and reservation release, retains exact falsey primary causes, carries real committed receipt information, and fences only this service after unconfirmed cleanup. The existing shared submit, evaluation epoch cancellation, history and publication model remains authoritative.

The new service methods are `inspectWorkerProfileExtents`, `inspectWorkerProfileExtentRegions`, `createWorkerProfileExtentExtrusion`, `inspectWorkerProfileExtentHistory`, and `editWorkerProfileExtent`. Creation requires explicit actual build/region/units/body policy and an exact active variant. Metadata and discovery do not launch a Native module merely to claim availability. Existing depth-specific rectangle-binding convenience stays scoped to its original feature; general physical field bindings and genuine current typed sketch sources remain the intended extent path.

Finite consumer limits remain explicit: whole ordinary V3 closed source boundaries; existing rectangle-only mechanical bore layout; existing positive cutter envelope; exact Shell-only sections; existing single-profile typed-history envelope. Counterbore/countersink retain their separately declared old `[0,T]` parent domain until a separately reviewed interval implementation exists. No implicit promotion is made for V4 arrangements, multi-region interfaces, unsupported frames or another backend/default.

The complete public application acceptance packet is still required, including metadata launch (description<=512 characters and independent schema<=4KiB), positive/negative/symmetric/two-sided geometry, raw typed fields, source/plane edits, no-op/refusals/travel, actual material review, Native queries/artifacts and three normal `.cad` persistence cycles. The fixed independent geometric/source/artifact criteria must be frozen before root's actual run; the source states in this document are not substitute runtime evidence.
