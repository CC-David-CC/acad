## Adapter obligations common to every chosen algorithm

1. **Input and ownership:** capture current registered source/feature/face/region, original curve IDs, source/frame/history/document revisions and actual Native handle in the existing Worker owner. New mechanical constructor binding is exactly featureId/faceId/sourceSha256/regionId/requestSha256 from guarded source and immutable actual constructor input, Worker-hashed and checked; it is not a caller success flag or Native-derived authored face ID. Keep old cohort contracts unchanged. Metadata reads return bounded facts, not HLR/topology buffers to Main.
2. **No semantic repair by library tolerance:** Source is not automatically closed/snap-welded because OCCT accepts nearby vertices. Geom2d InterCurveCurve defaults1e-6, MakePipeShell defaults Tol3d/BoundTol1e-4/angular1e-2, loft already explicitly uses1e-6, and GeomLib extension may change type. These are actual API behaviors to qualify/configure or refuse, not approval to change50pm or generic1e-9 gates. Use analytic source/finite domains first; library failure or no solution count is not a proof of sketch contradiction.
3. **Identity/history:** operation-local Generated/Modified/IsDeleted and actual detached-copy maps feed current source-span/selection descriptors. Compose source→working ancestry once; preserve lost/multiple/merged states. Output ordinals and sorted intersection roots never become public persistent IDs. A trim event requires current source-pair/interval/branch custody and stable authored output IDs; if continuation becomes ambiguous, require explicit repair/refuse, not nearest geometry or stale coordinates. Sketch constraint/generator references must be preserved or explicitly handled before acceptance.
4. **Publication:** one candidate source/history/material/J state, full suffix proof, then one publication; no temporary invalid accepted model or success-before-replay. Reuse `capturePipelineHistory`, current prepared command/physical guards, existing source-byte journal and nativeSave/Open validators. Reads/Open validate current derived data, never heal. Keep raw names/units and exact unrelated source, counters/highwater and accepted state through refusal/travel. General generated profile consumption must be explicit, not a global generator guard bypass.
5. **Failure and resources:** ordinary request/domain refusal, missing/ambiguous reference, algorithm nonconvergence, precision uncertainty, resource exhaustion, stale/cancel and cleanup-unknown are different outcomes. Preserve actual error/cause and postcommit knowledge. Fresh scratch/result reservations, cumulative name/mesh/work costs, exact fresh-name/pointer retirement and terminal unknown-dispatch/exchange classification use existing allocator/ownedKinds policy. Do not copy a release-on-quota callback into a helper that also retires; prior extent repair is the contract. New Native ports must use staged input capture, caught delivery, exact result-owned rollback and postcallback preservation fences; never delete a caller replacement or throw JS through live C++ RAII.
6. **Closure and qualification:** required exports/import roster, pure stager roots, emitted static/dynamic resources, factory/descriptor and bootstrap pins must describe the SAME actual source. Keep Native source/ABI/export inventory distinct from a mounted capability. A new owned port entails a new exact JS/WASM pair; Native source header existence alone enables nothing. Root alone composes/builds and runs one complete public workflow, then independent original-data/artifact checks and actual rendered review. Never certify an exported mesh from its volume/support samples alone.

Legacy Draw commands/research exports and `shape-io/curveIO.hpp` are not shortcuts: the latter emits unsupported/type-only records for several curves and contains legacy knot rewriting. `commonIO.hpp:pntRead` and legacy location exports also use float-facing transport.
