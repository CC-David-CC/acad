## Shared operation

`prepareRadius(pm, object, radius)` prepares the actual existing RadiusLength
constraint (`constants.length`) with a current Circle or Arc. The editor action
and closed-source Worker both call it. The first slice creates one numeric
literal radius, greater than0 and at most1,000,000 canonical millimeters.
The human form preserves its numeric literal string. A formula/typed name is
refused, never converted into a numeric literal. The existing human multi-selection action is retained as one transaction,
preparing every target through the same admission before any mutation; there is
no partially committed batch. Revision-bound single-target discovery is added. Existing imported named radius intent is not silently
removed or replaced by the new edit route.

Core registration required in Craft (root-owned): expose factory return
`applyClosedSketchRadius` as `craft.applyClosedSketchRadius(input, options)`;
optional service type has input `{revision:string,faceId:string,id:string,radius:number}`
and the same `{signal?,valid?}` options as diameter. The existing coordinator
owns source/frame/document/history/J/currentness and full-suffix publication.
No new journal kind, geometry store, feature identity or file version.

Desktop dedicated module registers `apply-closed-sketch-radius` with that exact
four-field schema. Creation receipt follows the existing sketch transition:
`{changed:true,faceId,dimension:{id,typeId:'RadiusLength',radius,status},revision,
persistence:'volatile-workspace',authoredUndo:true,
manufacturingAssignments:'review-if-present'}`. Status is actual fresh
`accepted` or `redundant`, not a global DOF or solvability claim.

`inspect-closed-sketch` derives RadiusLength targets with length units and the
current actual radius (not diameter). Existing edit/remove commands take the
inspected revision-bound constraint locator. Locators are never saved IDs,
caller-provided source, or Native topology ordinals. Radius edit currently
requires a positive numeric literal and refuses an existing named binding;
removal also refuses a named radius binding. Generic typed inventory/resolution
shares the actual length-field table, so imported name usage remains length-
valued; that recognition alone is not a qualified typed Circle extrusion path.
No named creation, typed source mutation, or formula-retargeting claim.

## Evidence and publication contract

Creation/edit/removal cold-replays the captured original and validates its
original equations and actual parameter ownership at captured coordinates.
A private polynomial dependency inventory authenticates allowed parameter
movement. Only represented-zero monomials are skipped and only exact LockPoint
or actual grounded fixed Params cut dependencies. Radius removal owns no
geometry motion. Creation at the already satisfied radius similarly owns no
motion. Warm admission output can supply only that authenticated delta.
Retained intent, unrelated geometry and IDs stay exact. Captured original
geometry, original registered domains/residuals, independent cold admission,
current50pm physical-coordinate replay policy and retained angular/non-coordinate
budgets all remain authoritative. No snapping or tolerance widening.

Fresh actual classifications may reactivate a retained redundant row after a
removal. They are derived from cold admission and revalidated at captured
coordinates, not copied as saved proof flags. A second disposable Worker repeats
THE ORIGINAL request, compares full source and receipt metadata, and only then
can the coordinator prepare the existing full-history replay and sketch-bytes
journal transaction. Solver residual arrays are not required to be bit-identical.

No engine bootstrap/Native ABI/default/cohort change is required: these are
normal sketch-Worker imports bundled through existing routes. Mirror branch
owns distinct additive routes in the same dispatcher/client/coordinator; merge
those additions serially without overwriting either packet.

## Remaining qualification

Arc from actual returned primitive/point IDs; lock centers and directed Arc
branches via real existing equations; create/discover/edit/remove radius;
prove diameter redundancy/conflict and recovery; preserve an unrelated Point,
source and body; travel; Save/sync/fresh Open/reedit. The independent after-whole
oracle reads actual .cad bytes and original source, checks Circle/Arc equations,
units/branch/IDs and Native measures/point observations. Component source is
not a Native/browser success or complete C03/C04 signoff.
