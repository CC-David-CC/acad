# Agent-path solid corpus: bounded three-engine control

The machine-readable `test/agent-cad-corpus/solid/receipt-20261105.json` records the same authored dimensions for all three engines through the registered `inspectWorkerSolids`, `createWorkerSolidBox` and `createWorkerSolidBoolean` craft methods. Each case ran in a fresh actual app context on the 4a3 local fixture, with a synthetic host lifetime and the fixture's strict self + wasm-unsafe-eval CSP. This is the shared core command surface used by an agent bridge; it is not a signed desktop command-bridge or deployment test. Served app, Worker and WASM hashes are recorded in the receipt. No test-only geometry or canvas manipulation was used.

For each engine, 12 cases passed: a 10 mm box; overlap union, subtraction and intersection; face-contact union; disconnected union; two separately published bodies; 0.001 mm and 100,000 mm boxes; rejection of zero and negative dimensions; and refusal of a second body using a different engine. A box has volume `x*y*z`; for two 10 mm cubes overlapping by 5 mm, expected intersection/subtraction are 500 mm³ and union is 1,500 mm³. Independent triangulated display-geometry volume and bounds were measured, with relative volume tolerance 0.3% and coordinate tolerance 2 ppm (plus small absolute floors). The disconnected-union component count is derived from shared vertex coordinates, not a BRep solid-cardinality proof. Zero/negative requests returned `INVALID_REQUEST` with no body. The cross-engine case returned `ENGINE_MISMATCH` before creating the second engine's body; the first body ID and mesh summaries matched before and after refusal in a separate repeat. A cross-engine Boolean was therefore **not tested**.

Five zero-volume intersection/subtraction cases per engine—disjoint, face-, edge- and point-contact intersection, and coincident subtraction—were explicitly refused (`EMPTY_OR_NON_SOLID_UNSUPPORTED` for OCC/SMLib and `UNSUPPORTED_CASE` for Manifold). Prior body IDs, engine, triangle-derived bounds/volume, triangle counts and vertex-connectivity summaries matched after each refusal; exact mesh bytes and native geometry were not compared. This is not successful empty-solid support.

Edge-contact union returned `ENGINE_FAILURE` for SMLib, with prior body summaries unchanged: that case is a **failure**, not a supported empty result. OCC and Manifold returned display geometry for edge-contact union, and all three returned it for point-contact union; those five cases are **not tested** for solid validity because volume, bounds and shared-vertex connectivity do not establish manifold topology. The common solid-command surface does not advertise extrusion, revolve, curved profiles, shell, fillet or STEP import/export; each is marked unsupported for this surface only, without claiming other engine-specific paths lack it.

Successful native snapshots were checked for the known transient-key patterns `mountId`, `worker-owned`, `nativeHandle` and `wasmPointer`; absence of those patterns is a limited serialization control, not a complete proof that all native pointers or handles are absent. No undo/redo, native fresh-context reopen, cross-kernel transfer, physical printer, or broad operation-catalog qualification is claimed here.

`provisional-r1.json`, `provisional-contact-r2.json` and `provisional-cross-r3.json` retain raw actual results. Initial r1 labels treated any mixed-engine rejection as a cross-engine Boolean pass and any invalid-input rejection as a pass. `finalize-receipt.py` tightens those labels using the captured error codes and summaries, preserves the raw files, merges the independently run contact and cross-engine cases and records the actual unsupported/unexercised surface. Test geometry and command execution were unchanged by that post-run classification correction. Run the corpus with `JSKETCHER_TEST_URL`, `CODI_TEST_CDP`, `PUPPETEER_CORE_PATH` and `CODI_RECEIPT` set; optional comma-separated `CODI_CASES` selects cases. Run `python3 test/agent-cad-corpus/solid/finalize-receipt.py` only against the retained provisional receipts to reproduce the checked-in final classification.
