# Worker rectangle operation candidate

This source-only candidate adds the distinct `WORKER_RECTANGLE_EXTRUDE_V1` history operation. It leaves legacy `EXTRUDE` intact. It accepts one selected authored sketch region on a principal XY datum plane, finite positive depth in millimeters, one separate OCC body, and no Boolean or engine conversion. Unsupported sketch/frame/constraint cases fail. The operation runs the strict sketch solve and residual checks for every replay even if stored admission flags say accepted; the disposable sketch worker serializes and hashes the solved bytes before the semantic worker and verified OCC mount consume them. Native history retains authored plane, sketch and operation inputs, not runtime asset paths, pointers, or mount handles.

Each candidate is bound to the existing evaluation owner, exact source bytes, storage service/revision, expression state, history/epoch, document generation and host lifetime. The parent project service must supply the separately reviewed `hasHostLifetime`/`isDocumentCurrent` contract. Without it the operation refuses. The mount and publication checks remain evaluation-owned; downstream unsupported legacy consumers and transient reference restrictions remain enforced by existing gates. This is not a general editable OCC bridge, Boolean, face-sketch, export, mesh-engine or completed mechanical plate qualification.

`npm run build` prepares the pinned interpreter wrapper and OCC WASM, builds the semantic worker, and emits the exact worker modules beside the OCI worker. `CODI_EMBED_NUMERIC=1 CODI_EMBED_MANIFOLD=1` is required for the qualified CSP configuration. A desktop app package must add the emitted OCI worker, portable wrapper, pinned WASM, four sibling `.mjs` modules, and hashed semantic worker to its closed asset inventory; it must separately bind host/frame/account lifetime before exposing the action. No site or desktop package was deployed here.

A strict-CSP disposable Chromium fixture exercised the actual wizard and craft API, source solve, worker mount, 8 vertices/12 edges/6 faces and world bounds for a translated 100×50×20 mm extrusion; editor width edit to 150 mm, depth history edit, failed edit/history retention, undo/redo, native snapshot/reopen, held-solve document reset and host abort, missing host binding, and contradictory constraints marked accepted. The fixture uses the real host-lifetime binder with a test-owned AbortController; it does not prove actual signed WebOS account/window integration. Snapshot checks reject persisted worker asset paths, runtime handles and worker metadata. Actual regenerated shape tests do not qualify all geometry or downstream operations.

The test build was made from base `0e4c1d5f` plus the source changes in this checkpoint; its `.rev` names the base because it was built before the checkpoint commit. The result receipt records actual emitted asset hashes, not a claim of an already-committed clean build. Run the node and browser checks using `test/webos/run-worker-rectangle-check.py` with a pinned source interpreter, OCC JS/WASM, Puppeteer and loopback Chromium; this uses temporary profiles and removes the fixture. The branch intentionally has no public activation.

The original Worker proof allowed blob scripts. The signed-policy negative and subsequent embedded-worker candidate are recorded in `EMBEDDED-OCI-WORKER-20261104.md`; do not treat the earlier fixture as signed-CSP evidence.
