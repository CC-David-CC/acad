# Signed CAD reopen timeout: bounded diagnosis

The clean-runtime signed desktop test at `8a9f79d8` previously timed out reopening a saved prism. The earlier b30 signed run also timed out once; traced and later untraced b30 runs passed. There is no established root cause. No timeout or product behavior was changed.

A read-only CDP inspection after the clean-runtime failure saw only the visible empty app frame, no processing or engine owner, and no held/pending Web Locks. The failed hidden candidate was already removed by the host, so this is not evidence of its state during the stall. The project rebuild loop uses a 25 ms timer while waiting for expected history length/pointer and an idle craft pipeline; it is not itself an animation-frame wait.

Using the same disposable signed fixture on loopback 20054, a warm existing Chromium profile with a test-only one-second per-frame sampler passed the full signed prism and dependent-hole flow. Ten samples covered four reopens; the longest sampled reopen had four ticks. A candidate was observed with one candidate owner, `processing=true` and the sketch-solver Web Lock held, later with history length 3, pointer 2, `processing=false`, one accepted owner and no locks. No pending lock appeared in these successful samples. Sampling is coarse and can alter timing; it does not exclude short-lived waits or establish what happened in the earlier failure.

Two additional runs used fresh Chromium profiles on separate ports, one sampled and one without the sampler or `evaluateOnNewDocument` trace flag. Both passed the signed flow. The underlying source test already installs a Worker diagnostic wrapper during the earlier extrusion step, so the latter is not entirely instrumentation-free. These profiles were new, but the OS caches and fixture were warm. The tested browsers and their two disposable profiles were stopped/removed; the root-owned server and browser were left untouched. The test creates disposable fixture accounts and operates on their own test files; this is not a public-site test.
