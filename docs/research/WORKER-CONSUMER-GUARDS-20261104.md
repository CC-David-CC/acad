# Worker geometry consumer admission

The unpublished worker prism projection is not an in-page OCC pointer or a
Native Mesh/Manifold operand. Its model tag declares compatibility; it does
not authorize operations or replace the candidate owner's lifetime checks.

Materialized craft operations reject worker operands before invoking legacy
commands, including implicit Boolean targets. The OCI proxy preflights all
direct model operands, refuses portable worker IDs as raw legacy names, and
caches a registration only after success. A new object with the same ID must
register again. `occIO.pushModel` now checks the underlying numeric command
status instead of unconditionally reporting success. OCC Boolean preparation
does not silently drop failed pushes. Construction planes are excluded only
from implicit solid targets; explicit incompatible operands fail.

Classifiers reject absent/invalid legacy pointers. Topology analyzers, fillet,
pattern, legacy sketch/craft routes and STL/3MF exports reject the worker
representation before their local kernel/export work. Native Boolean admission
checks the complete target/tool mesh set before its first asynchronous job.
There is no automatic B-rep/mesh conversion or claim of engine parity.

actual model-wrapper admission tests with explicit kernel spies, including
failed cache registration, underlying nonzero registration status, mixed and
implicit targets, raw classifier pointers and Native preflight. These empty
topology fixtures are not real-geometry proof. `tsc --noEmit` and the distinct
Native/OCC classifier test pass the current source. The resource pool's 12
