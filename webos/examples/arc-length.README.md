# Authored circular Arc length — source packet

This recipe uses the ordinary scoped browser command facade (`agent.execute`)
with a caller's current, inspected face and Arc identities. It has not run and
is not qualification evidence. The full public lifecycle packet requires its
coordinated Core source and an independently reviewed grouped build/workflow.

Import `createArcLengthExample` and pass the authorized bound CAD agent facade.
Call `create(faceId, arcId)`, `promote`, `edit(..., value)`, `demote`, `remove`.
Each operation rediscovers the current revision/locator. Save separately with
the ordinary native project Save command. The native ruler stores its actual
Arc ID and label offset only; its length and driving/reference role are derived.

Measurements use the entire authored circular interval, including explicit
proper/full CCW branches. They are not endpoint chord distances. Canonical
lengths are millimeters; display units use the normal document formatter.
Role conversion retains current geometry. Existing driver edits are separate
operations that may change supported geometry or explicitly reject the edit.

Generated targets and role conversion in typed document mode remain unsupported
by the bounded current mutation policy. Bound drivers cannot silently become
literal drivers. Native Save/Open carries the ruler and equation. DXF export
with an Arc length ruler explicitly refuses until arc-length annotation export
exists; it must not silently lose the annotation. This limitation adds no claim
about STEP/3MF or other drawing output.
