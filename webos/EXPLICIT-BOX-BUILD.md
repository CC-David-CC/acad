# Explicit box engine build

create-worker-solid-box accepts optional engineRevision as sha256:JS:WASM, alongside the existing required revision/version/unit/engine/origin/dimensions. The descriptor leaves it optional but rejects malformed supplied values. Core resolves only a registered exact build, refuses a mismatch with existing part outputs/history, and derives the admission budget for the selected build. No implicit conversion, new engine default, alternate file store or saved schema.

This supports the upcoming shell-capable cohort; its availability remains distinct from catalog identity. Agent discovers the shell cohort, explicitly creates its box on that revision, then uses real advertised builder-provenance face IDs. Never persist response-local native indices. Source implemented; complete shell workflow qualification pending.
